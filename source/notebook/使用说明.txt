【翻页笔记本使用说明】

一、目录结构（一本笔记 = 一个文件夹）
    source/notebook/
      index.html          ← 书架 + 翻页相册页面，不用改
      shell.css           ← 侧边栏 / 书架样式，不用改
      shell.js            ← 书目加载与选书逻辑，不用改
      数学笔记/           ← 一本笔记
        01.jpg 02.jpg …   ← 图片按编号顺序直接放在文件夹里
      示例笔记/           ← 演示用的一本（可整个删掉）
        01.jpg … 05.jpg

二、新增或修改一本笔记（不需要改任何代码）
    1. 在 source/notebook 下新建一个文件夹，文件夹名就是这本书显示的名字。
       想让顺序固定，可以加编号前缀：01-数学笔记、02-线性代数（前缀不会显示出来）。
    2. 把图片放进这个文件夹，文件名从 01 开始连续编号：01.jpg、02.jpg、03.jpg…
       支持 jpg / jpeg / png / webp。也可以把图片放进该文件夹里的 photos 子文件夹。
    3. 重新生成站点：hexo generate
       本地调试：重启 hexo server，然后打开 /notebook/
    4. 打开 /notebook/ 先看到的是书架，点一本书才进入翻页阅读；
       左侧书目（窄屏点左上角 ☰）可以随时换书。

三、规则与限制
    · 编号必须从 01 开始；同一本书里连续缺号达到 5 张，后面的图片就不再显示。
    · 单本最多 500 页。
    · 书目和页数由 scripts/notebook-books.js 在构建时扫描生成（输出 /notebook/books.json），
      不需要手工维护任何清单文件。
    · 增删图片后都要重新生成站点，否则页面读到的还是上一次的清单。

四、其它
    · 本页是纯静态页面：图片直接放在 GitHub 仓库里，没有任何上传功能。
    · 入口：首页导航栏的「笔记」（与「相册」同级）。
